# Contributing to the control repository

Open a pull request in [SNodeC/.github](https://github.com/SNodeC/.github/pulls).
Keep repository identity in `catalog.yml`; build settings belong in the owning
repository's `.snodec/repo.yml`. Do not edit generated `profile/README.md` by hand.

Run the generator and checks described in [README.md](README.md). For an identity
change, cite the source or mark the summary `confirm: true`. Do not change other
repositories, licences, package pipelines or release tags as part of Phase 1.
