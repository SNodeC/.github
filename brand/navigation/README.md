# Page-header inputs

Identity/accent policy remains in `catalog.yml` and `brand/tokens.yml`. These extracted graphics are the exact repository-specific shapes from the current compact page banners, not figures from SNode.C-Landingpages. Only the original placement transform was removed; geometry and graphic colours were retained. The renderer centres/scales them to 44px high in the prescribed 1280×56 header. Text, background and accent strip follow the new approved specification.
