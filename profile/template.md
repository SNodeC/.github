**Write the protocol. Run the messages. Ship it signed.**

SNode.C builds event-driven networking in C++. At its centre is [SNode.C](https://github.com/SNodeC/snode.c#banner), a C++20 framework for Linux; around it are MQTT and AI suites, a coding-agent workspace and signed packages for six Linux distributions.

## Install

SNode.C and MQTTSuite are available as signed packages from [Packages](https://github.com/SNodeC/Packages#banner). Pick the guide for your installed distribution; each covers quick and custom installation, manual repository setup and updates.

| Distribution | Install guide |
| --- | --- |
| OpenWrt | [OpenWrt guide](https://github.com/SNodeC/Packages/blob/main/docs/installation/openwrt.md#banner) |
| Raspberry Pi OS | [Raspberry Pi OS guide](https://github.com/SNodeC/Packages/blob/main/docs/installation/raspberry-pi-os.md#banner) |
| Debian | [Debian guide](https://github.com/SNodeC/Packages/blob/main/docs/installation/debian.md#banner) |
| Ubuntu | [Ubuntu guide](https://github.com/SNodeC/Packages/blob/main/docs/installation/ubuntu.md#banner) |
| Rocky Linux | [Rocky Linux guide](https://github.com/SNodeC/Packages/blob/main/docs/installation/rocky-linux.md#banner) |
| Fedora | [Fedora guide](https://github.com/SNodeC/Packages/blob/main/docs/installation/fedora.md#banner) |

Supported releases, architectures and current builds: [package status](https://github.com/SNodeC/Packages/blob/main/status/README.md#banner).
